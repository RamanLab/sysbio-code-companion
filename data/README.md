# Data

| File | What it is | Source |
|---|---|---|
| `e_coli_core.xml` | *E. coli* core metabolic model (95 reactions, 72 metabolites, 137 genes), SBML Level 3 with the FBC package | BiGG Models `e_coli_core` (Orth, Fleming & Palsson, 2010, *EcoSal Plus*, doi:10.1128/ecosalplus.10.2.1), as distributed with COBRApy 0.32.1 and written out with `cobra.io.write_sbml_model` |
| `e_coli_core.mat` | The same model in COBRA Toolbox format, for the MATLAB examples (reading SBML in MATLAB needs a compiled libSBML, which is not available for every release) | Generated from `e_coli_core.xml` by `tools/make_mat_model.py`; regenerate it whenever the `.xml` changes |
| `iML1515.xml.gz` | *E. coli* K-12 MG1655 genome-scale metabolic model iML1515 (2712 reactions, 1877 metabolites, 1516 genes), SBML Level 3 with the FBC package, gzipped | BiGG Models `iML1515` (Monk et al., 2017, *Nat. Biotechnol.*, doi:10.1038/nbt.3956; King et al., 2016, *Nucleic Acids Res.*, doi:10.1093/nar/gkv1049), <http://bigg.ucsd.edu/static/models/iML1515.xml>, fetched November 2026; SHA-256 of the uncompressed file in `iML1515.sha256` |
| `iML1515.mat` | The same model in COBRA Toolbox format, for the MATLAB examples | Converted from the BiGG SBML with `cobra.io.save_matlab_model` (COBRApy 0.32.1), as `tools/make_mat_model.py` does for the core model |
| `precise_log_tpm.csv` | Expression, as log2(TPM + 1), of the 1492 iML1515 genes in six RNA-seq samples of wild-type *E. coli* MG1655, grown aerobically in M9 medium on glucose, xylose, glycerol, acetate (two studies) and fructose | PRECISE compendium (Sastry et al., 2019, *Nat. Commun.* 10:5536, doi:10.1038/s41467-019-13483-w), <https://github.com/SBRG/precise-db>, MIT licence; extracted with `tools/make_precise_subset.py` |
| `precise_samples.csv` | The six samples: carbon source, measured growth rate, study and DOI | As above, from PRECISE `metadata.csv` |
| `mm_replicates.csv` | 200 simulated datasets of Michaelis–Menten rates (mM/s) at the nine substrate concentrations of Exercise 6.5 (header row), with vmax = 2.5 mM/s, KM = 0.8 mM and Gaussian noise of standard deviation 0.1 mM/s | Generated by `tools/make_mm_replicates.py` (seed 2021); rerunning it reproduces the file |
| `karate_edges.csv` | Zachary's karate club: the 78 friendships among its 34 members (numbered 1 to 34) | Zachary (1977), *J. Anthropol. Res.* 33:452–473; as distributed with NetworkX (`karate_club_graph`), unweighted |
| `karate_factions.csv` | The faction each member joined after the club split ("Mr. Hi", member 1, or "Officer", member 34) | As above |
| `ecoli_trn.csv` | *E. coli* transcriptional regulatory network: 4170 regulator → target edges among 1773 nodes, with the sign of each interaction (`+`, `-`, `+-` or `?`); each regulator, including complexes, is one node | Transcription factor interactions from RegulonDB, as distributed with PRECISE-1K (Lamoureux et al., 2023, *Nucleic Acids Res.* 51:10176, doi:10.1093/nar/gkad750), <https://github.com/SBRG/precise1k>, MIT licence; built with `tools/make_trn.py` |
| `precise1k_carbon_log_tpm.csv` | Expression, as log2(TPM + 1), of 44 genes of central carbon and glycerol metabolism, in 308 RNA-seq samples of wild-type *E. coli* grown on glucose (200) or glycerol (108) | PRECISE-1K, as above; extracted with `tools/make_precise1k_subset.py` |
| `precise1k_carbon_samples.csv` | The 308 samples: carbon source, study and strain | As above |
| `competitive_inhibition.csv` | Initial reaction rates $v$ (mmol L⁻¹ s⁻¹) at 20 substrate concentrations $S$ (mM), for an enzyme with a competitive inhibitor at $I$ = 10 mM (`v_I10`) and $I$ = 20 mM (`v_I20`) | BT5240 laboratory exercise on parameter estimation (Lab 8); also the basis of Exercise 6.1 in the book |
| `ecoli_string_ppi.csv` | *E. coli* K-12 MG1655 protein interaction network: 32,244 undirected links with a STRING combined score of at least 700 ("high confidence") among 4,006 proteins | STRING v12.0, taxon 511145 (Szklarczyk et al., 2023, *Nucleic Acids Res.*, doi:10.1093/nar/gkac1000), CC BY 4.0; `511145.protein.links.v12.0.txt.gz` (SHA-256 `e60afb17…19c`), filtered by `tools/fetch_string.py` |
| `ecoli_string_proteins.csv` | STRING identifier, preferred gene name and length (amino acids) of each of the 4,141 proteins | STRING v12.0, `511145.protein.info.v12.0.txt.gz` (SHA-256 `f86c3ec4…076`), via `tools/fetch_string.py` |
| `ecoli_netgenes_essential.csv` | The 790 *E. coli* K-12 MG1655 genes predicted to be essential, with STRING identifier, gene name, annotation and prediction score (%) | NetGenes database (Azhagesan, Ravindran & Raman, 2018, *PLOS ONE*, doi:10.1371/journal.pone.0208722), <https://rbc-dsai-iitm.github.io/NetGenes/>, file `CSV/Escherichia coli K12 MG1655.csv`, used with the authors' permission; HTML entities in the annotations decoded |
| `gene_expression_timecourse.csv` | Synthetic time course of mRNA and protein (molecules per cell) every half hour for 12 h after a gene is switched on, with 10% relative noise | Generated by `tools/make_expression_data.py` (true parameters in that script); rerunning it reproduces the file |

When adding a file, record here where it came from and under what terms.
